# HomeAssistantAgent

This add-on runs a PydanticAI chat agent backed by the OpenAI `GPT-4o` model.
Configure the `openai_api_key` option in the add-on settings to supply your API key.

## Versioning

Version bumps are automated after changes land in `main`; the workflow updates `homeassistantagent/config.json` and commits the new patch version automatically.
